# Spark 1.8

- People You May Know appears after the third feed post. Reels cards appear after the sixth. Short feeds append these sections once after the available posts. Reel cards use the author's image and open the selected reel; they do not download entire videos for thumbnails.
- Tapping a comment opens six reactions and Reply, with Edit/Delete for the author. Existing quick Like/Reply controls remain. Edited comments have an Edited label. Database ownership and post visibility protect edits/reactions.
- Chat marks only received messages visible in the foreground chat viewport as seen, after 400ms. The first server timestamp is retained and displayed to the sender; regular polling syncs it within roughly four seconds while chat is open.
- Senders can edit or unsend their messages. Unsend replaces content with a tombstone for both participants. Content already viewed or copied by another person cannot be recalled from that person's memory/device.
- Image attachments have a View once toggle. Reserved media paths cannot be downloaded/signed through ordinary Storage APIs, even by the uploader. An authenticated Edge Function checks the JWT with Auth and uses a service-only atomic claim to return the recipient's first image response. No permanent URL or secret enters Android. The image viewer is screenshot-protected, closes on background, and keeps bytes out of the normal image cache. Opening consumes access; a network failure after consumption may prevent viewing. Unopened uploads remain in private storage; unsent records lose access, but this version does not have a scheduled orphan-file cleanup job.
- Calls use microphone echo cancellation/noise suppression, explicit remote audio playback, Android communication audio focus/mode, Speaker control and route restoration on exit. Direct WebRTC uses STUN. No TURN relay is configured, so calls cannot be guaranteed on restrictive/mobile NAT networks. Incoming ringing currently works while Spark is open, not through a background push service. Physical two-phone audio was not verified in this environment.

Run backend/verify-social-chat.sql (rollback-only) and the updated base verification suite.
